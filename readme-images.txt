IMAGE SPECIFICATIONS:
---------------------
- Format: JPG (preferred) or PNG
- Orientation: VERTICAL/PORTRAIT (3:4 ratio ideal)
- Minimum size: 1200px wide x 1600px tall
- Ideal size: 1500px x 2000px
- Compression: 80-90% quality
- File size: Under 500KB per image
- Color profile: sRGB

The vertical format is important because images take up 60% of screen width.


TIPS:
-----
1. Vertical/portrait orientation works best with this layout
2. Images with depth work well with parallax
3. Clear architectural shots preferred
4. Avoid busy backgrounds
5. Consider how white navigation will appear on top
